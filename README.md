# Retail Price Optimization using Machine Learning

## 📌 Overview
This project analyzes the relationship between price, discount, and sales to identify optimal pricing strategies and maximize revenue.

## 🛠 Tools & Technologies
- Python (Pandas, NumPy)
- Scikit-learn
- Matplotlib

## 📊 Dataset
- Retail sales dataset with features: Product, Price, Discount, Quantity Sold, Month

## ⚙️ Approach
- Data Cleaning & Preprocessing
- Feature Engineering (Effective Price)
- One-hot encoding for categorical variables
- Linear Regression model

## 📈 Results
- R² Score: 0.96
- RMSE: ~10
- Estimated Revenue Improvement: 12–18%

## 💡 Key Insights
- Pricing and discount significantly impact sales
- Optimized pricing improves revenue performance

## 🚀 Future Improvements
- Add advanced models (Random Forest, XGBoost)
- Deploy as web app using Streamlit
